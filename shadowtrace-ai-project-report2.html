1. Introduction

In today's digitally connected world, cybersecurity threats are growing at an alarming rate. Organizations and individuals face attacks such as SQL injections, brute-force login attempts, ransomware, phishing, and Distributed Denial-of-Service (DDoS) attacks on a daily basis. Detecting and responding to these threats quickly is critical to protecting sensitive data and maintaining system integrity.

ShadowTrace AI is a web-based cybersecurity intelligence dashboard developed using Python and the Streamlit framework. The application simulates an AI-powered security monitoring platform that allows users to visualize security events, analyze suspicious IP addresses and domains, and scan system logs for threat indicators — all through a beginner-friendly, single-file implementation.

The project is designed to demonstrate core concepts of Python programming, data visualization, and cybersecurity awareness in an interactive and visually engaging manner.

2. Problem Statement

Most enterprise-grade cybersecurity tools are complex, expensive, and difficult for beginners to understand or operate. There is a lack of accessible, educational tools that demonstrate how threat detection, log analysis, and security dashboards work in practice.

This project addresses that gap by providing a simplified, simulated cybersecurity platform that is easy to run locally, visually informative, and educational for students and beginners learning about network security and Python application development.

3. Objectives

  • Build an interactive, real-time cybersecurity monitoring dashboard using Python and Streamlit.
  • Implement a simulated AI threat analyzer that evaluates IP addresses and domains for risk.
  • Develop a keyword-based log scanner that identifies common attack patterns in system logs.
  • Visualize security data using charts, tables, and color-coded severity indicators.
  • Create a professional, dark-themed cybersecurity UI using custom CSS within Streamlit.
  • Deliver the entire application in a single Python file, making it beginner-friendly and portable.

5. System Architecture

ShadowTrace AI follows a simple single-page application (SPA) architecture driven by Streamlit's reactive execution model. The entire application lives in one file, app.py, divided into logical sections:

LayerDescription
Configuration LayerPage title, icon, layout settings via st.set_page_config()
Styling LayerCustom CSS injected via st.markdown(unsafe_allow_html=True)
Data LayerHelper functions that generate simulated events, analyze logs, produce random IPs
Navigation LayerSidebar with st.radio() acting as a multi-page router
Presentation LayerFour page views rendered conditionally based on selected navigation item

6. Module Description

6.1 Dashboard Module

🏠 Security Dashboard

The landing page displaying four KPI metric cards (active threats, blocked attacks, monitored IPs, critical alerts), a 24-hour dual-series line chart, a top-6 country bar chart, four severity breakdown cards, and a live event feed table with 15 simulated events. An auto-refresh toggle allows data to update at a user-defined interval (5–60 seconds).

6.2 Threat Analyzer Module

🔍 AI Threat Analyzer

Users enter an IP address or domain, select a scan type (Quick / Deep / Full Recon), and click "Run AI Analysis". The system generates a risk score (0–100), threat level, origin country, 2–7 detected findings with port numbers and confidence percentages, 4 AI security recommendations, and an open ports table.

6.3 Log Scanner Module

📋 AI Log Scanner

Users paste raw system logs into a text area (or use the sample log button). The analyze_log_text() function scans for 18 threat keywords. Each match is reported with threat name, severity, triggering keyword, and confidence score. A summary DataFrame and severity bar chart are displayed.

6.4 About Module

ℹ️ About Page

A static informational page describing the application's purpose, AI logic explanation, tech stack cards, and a disclaimer that all data is simulated.

7. AI / Detection Logic

ShadowTrace AI uses rule-based simulated intelligence — an ideal starting point for understanding how real threat-detection systems work before introducing machine learning models.

7.1 Threat Analyzer Logic

A random integer (10–99) is generated as the risk score. A threshold-based rule maps the score to a severity level:

risk_score > 80 → Critical
risk_score > 60 → High
risk_score > 40 → Medium
risk_score ≤ 40 → Low

7.2 Log Scanner Keywords

The analyze_log_text() function maintains a dictionary of 18 threat patterns:

KeywordDetected ThreatSeverity
failed loginBrute ForceHigh
select * fromSQL InjectionCritical

10. How to Run the Application

Prerequisites

  • Python 3.8 or higher installed on the system
  • pip (Python package manager)
  • An internet connection for the initial package installation

Step 1 — Install dependencies

pip install -r requirements.txt

Step 2 — Run the application

streamlit run app.py

Step 3 — Open in browser

Streamlit automatically opens the default browser at http://localhost:8501.

💡 It is good practice to create an isolated environment with python -m venv venv and activate it before installing packages to keep your global Python installation clean.

12. Limitations

  • All data is randomly simulated — no real network traffic or threat feeds are used.
  • The "AI" is rule-based keyword matching, not a trained machine learning model.
  • No user authentication or role-based access control.
  • No persistent storage — data resets on every page interaction.
  • No real IP geolocation or WHOIS lookup is performed.

13. Future Enhancements

14. Conclusion

ShadowTrace AI successfully demonstrates how Python and Streamlit can be used to build a fully functional, visually professional cybersecurity dashboard in a single file. The project covers a broad range of beginner-to-intermediate Python concepts including function definitions, dictionary lookups, list comprehensions, DataFrame manipulation, session state, conditional rendering, and custom HTML/CSS injection.

From a cybersecurity education perspective, the application introduces learners to key threat categories — SQL injection, brute force, ransomware, DDoS, privilege escalation — and shows how real-world tools classify, score, and present these threats in an analyst-friendly interface.
